# FPT Stock Simulator

A mobile-first, responsive website where visitors practice buying, selling and short selling simulated FPT shares with virtual money. Prices are randomly generated; this is not real market data and not investment advice.

Pages: `index.html` (landing), `trade.html`, `portfolio.html`, `learn.html`.
Files: `css/style.css`, `js/ui.js`, `js/main.js`, `js/trade.js`, `js/portfolio.js`, `js/learn.js`.
